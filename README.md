# Block Unknown Calls – Privacy Policy

Welcome to the official Privacy Policy repository for **Block Unknown Calls**, an Android application designed to help users manage unwanted incoming calls and messages.

## About the App

Block Unknown Calls is designed to help users control incoming communications by distinguishing between saved contacts and unknown numbers.

## Privacy Policy

Our Privacy Policy explains how the application accesses, processes, stores, and protects user information.

## Information and Permissions

Depending on the features enabled and the Android version, the application may request permissions related to:

- Contacts
- Incoming call screening
- SMS filtering
- Notifications
- Other permissions required for app functionality

The actual use of these permissions is described in the Privacy Policy.

## Privacy and Data Protection

We aim to respect user privacy and handle information responsibly. Please review the Privacy Policy to understand the application's actual data practices, including storage, processing, and any data sharing.
